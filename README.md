# Student Enrollment & Course Management System (SECMS)

A web-based system to manage student enrollment, course registration, and academic records.

## Features
- Student Registration & Login
- Course Enrollment & Management
- Admin Dashboard
- Faculty & Student Portals
- Attendance & Grade Tracking

## Tech Stack
- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js / PHP / Java
- Database: MySQL / MongoDB

## Modules
1. Admin - Manage students, courses, reports
2. Student - Enroll courses, view grades
3. Faculty - Manage attendance, grades

## How to Run
1. Clone repository
2. Setup database
3. Run project
